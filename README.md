# Sebbielog

A static ordering website for a salted egg factory in Santa Cruz, Laguna.

## Pages

- `index.html` — Home page and egg ordering desk
- `about.html` — Factory story, owners, and egg categories
- `contact.html` — Contact information and inquiry form demo

Open `index.html` in a browser to use the website. Orders are stored in the browser's local storage on that device.
